# 📚 Student Task Manager

A modern web app to help students organize assignments, track deadlines & boost productivity.

### 🔗 Live Demo
**[👉 Click Here to Visit Live Site](https://sanjanamalabagi.github.io/Student-Task-Manager-/)**

### ✨ Features
- ✅ Add, Edit, Delete Tasks
- 🎯 Priority Levels (High/Medium/Low)
- 📁 Categories & Due Dates
- 📊 Productivity Dashboard
- 💾 Saves Automatically (LocalStorage)
- 📱 Mobile Responsive

### 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- LocalStorage API
- GitHub Pages

### 🚀 How to Use
1. Open live site
2. Add tasks with priority & date
3. Track progress
4. Edit/Delete anytime
